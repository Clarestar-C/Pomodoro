# Pomodoro

**Overview**

A clean, web-based Pomodoro app designed for deep focus. It blends a aesthetic visual style with full offline capabilities, functioning as a standalone app on desktop and mobile.

**Key Highlights**

* **Aesthetic & Minimalist Design:** Features aesthetic UI, interactive SVG progress ring, customizable color palettes, and ambient soundscapes.
* **Installable PWA:** Works offline and can be downloaded directly to your home screen or desktop as a native app via Progressive Web App (PWA) support.
* **Customizable Timers:** Adjust session lengths easily using built-in stepper controls for Pomodoro, Short Break, and Long Break modes.
* **Progress Tracking:** Saves completed sessions and total focus time locally without requiring an account.
* **Keyboard Shortcuts:** Quick hotkeys for instant play, pause, reset, and mode switching.
